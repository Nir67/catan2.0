# CATAN 2.0

משחק קטאן לחברים בעברית, עם משחק הבסיס, ערים ואבירים, יורדי הים במפת איים מקורית ווריאנט השודד הידידותי, ל־3–4 שחקנים. בוחרים את ההרחבות ביצירת החדר ובלובי.

```sh
cd catan-game
npm ci
npm run dev
```

ב־Codespaces פותחים את פורט **5173** דרך Ports → Open in Browser. הפקודה מפעילה גם את שרת המשחק וגם את הממשק.
