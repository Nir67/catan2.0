# CATAN 2.0

משחק קטאן לחברים בעברית, עם בחירה בין משחק הבסיס לבין הרחבת ערים ואבירים, ל־3–4 שחקנים.

```sh
cd catan-game
npm ci
npm run dev
```

ב־Codespaces פותחים את פורט **5173** דרך Ports → Open in Browser. הפקודה מפעילה גם את שרת המשחק וגם את הממשק.

[הוראות משחק, תיעוד החוקים, שמירה ושחזור ובדיקות](catan-game/README.md)
